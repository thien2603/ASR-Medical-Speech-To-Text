# Bản publish lịch sử

`kaggle_publish/` giữ nguyên bản notebook huấn luyện và metadata đã publish trước khi tổ chức lại repository. Bản này từng gồm bước chấm test sau train; recipe hiện tại ở `training/vietmed/` đã tách chấm test thành lệnh evaluation riêng.

Không dùng thư mục này làm entry point mặc định. Các báo cáo/số liệu cũ vẫn mô tả lần chạy lịch sử của chúng.
